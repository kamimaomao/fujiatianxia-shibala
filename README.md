## ✨ 可玩 MVP 核心特性（`mvp/`）

1. **黄金 9:16 四段式单手人体工学（`8% + 54% + 16% + 22%`）**：
   - 顶栏资源滚轮跳字与霸主下圈手笔明牌预警（点击即看反制攻略）；
   - 外环 `8×8` 共 28 格顺时针 3D 微缩沙盘 + 内侧 `6×6` **永不切屏中央舞台**；前方 `2~12` 步实时落点预览（`7` 点琥珀金高亮、高危敌城红光闪烁）；
   - 构筑舱支持一键秒切先锋（张飞/赵云）、四槽装备「左旧右新·即换即融」、3 张棋盘锦囊（含《安步当车》1~6 步指哪打哪）+ 2 张战斗奇策；
   - 底部大拇指热区配备鎏金立体「掷骰 十八啦！」大键、「加注 ×1/×2/×3」火焰拨片、自动连掷托管与凶格救急「气运签改命重摇！」。
2. **霸主同步落子（零等待）与爆笑城建博弈**：
   - 玩家掷 2D6 的同刻，曹操与孙权车驾同步走 1D6 买地、升城、踩玩家城喷金币交租、挨「箭塔」射瘫或现金见底触发「割地抵债」乃至穿碎花大裤衩破产跑路！
   - 踩进敌城固定弹出四色宝石键 **「踩城四择」**（缴交过路费 / 骑木马单挑 / 地形野战 / 机关攻城），明示真实胜算百分比，并随主公名望正邪动态改写为 **「开芭乐票（邪道免付赖账）」** 或 **「开城劝降（正道减损夺城）」**。
   - **不切屏骑木马单挑舞台**：弹簧摇摇木马对冲 + 诸葛亮 vs 郭嘉羽扇口斗互喷气泡 + **2.0 秒发光「拍出战斗奇策！」高光交互窗** + 50% 败北放水扑街黑乌鸦飞过喜剧演出。
   - **过圈一屏置业 + 里民大会冻蒜 + 关底决战三段**：支持「阿伯代办」一键最优盖楼（含全盘限一尊绿烟袅袅的「屎王神」与「箭塔」）、政见三选一高呼「冻蒜！」，并在第 8/15 圈终局将全盘房产身家化作万门火炮三段轰击天命魔王「赤壁铁索巨舰·魔化曹丞相」！
3. **纯静态零构建 & 离线 `file://` 双击直开**：
   - 纯原生 HTML5 + CSS3 + JavaScript（WebAudio API 程序化合成陶碗骰声、铜锣唢呐、弹簧木马与火炮音效），无任何外部依赖或打包步骤，克隆仓库后直接双击 `mvp/index.html` 即可离线畅玩。

1. 直接双击打开 [`mvp/index.html`](./mvp/index.html) 即可离线游玩；
2. 或在根目录启动任意静态服务后在手机/桌面浏览器访问：
   ```bash

   ```
