## 第一章：高水准商业立项方法论与喜剧游戏化引擎

本章提炼自本机沉淀的四套核心方法论技能（`game-design-proposal-writer`、`game-concept-architect`、`game-experience-density-optimizer`、`sitcom-game-designer`），作为 Fable 5.2 构建总纲与项目立项书的结构准绳。

### 1.1 商业游戏立项书的黄金推导链与硬门禁（源自 `GameDesignOS`）

高水准商业立项案绝非「世界观设定 + 系统名称堆砌」，而是一份**推动资源投入决策的论证契约**，必须回答三个终极问题：**为什么现在值得做？做成什么样算成立？下一步用多少资源去验证什么核心假设？**

#### 1.1.1 强制推导主线（Proposal Spine）
```text
Concept Seed（题材/玩法/情绪种子）
  └─> Player Verb Inventory（玩家80%时间反复执行的直接动词与脑内权衡）
        └─> Design Nucleus Options（核心取舍候选对比与选型理由）
              └─> Player Promise（对外宣传买点承诺 / 前10分钟首局承诺 / 长线留存承诺）
                    └─> Core Loop & Key Systems（行动-选择-风险-反馈-奖励-新约束，所有系统必须回连循环）
                          └─> Platform & Business Fit（9:16竖屏单手约束 × IAP/IAA混合变现同构）
                                └─> Scope Gate（MVP / Vertical Slice / Release / Post-launch / 砍项清单）
                                      └─> Metrics, Risk & Decision Request（假设回连指标、风险登记册、立项决策请求）
```

#### 1.1.2 商业策划案六大硬规则（防翻车自检门）
1. **反题材幻觉（Anti-Theme Illusion）**：不能把「三国 + 大富翁 + 肉鸽」的名词拼贴当成差异化；只有当题材组合**改变了玩家每分钟的取舍行为**（如：在单手绕圈升阶压力下权衡“交过路费苟活”还是“派武将骑木马单挑搏免单夺城”），才构成真正的设计核（Design Nucleus）。
2. **受众画像去标签化**：禁止只写“25-40岁泛休闲男性/情怀玩家”。必须写清玩家的**核心渴望（Desire）、高频行为、付费意愿锚点与明确拒绝点**（如：渴望单局10分钟内体验买地收租把对手逼破产的爽感与台式冷幽默解压；拒绝传统单机大富翁一局3小时的垃圾时间、拒绝重度SLG被大佬半夜沦陷的社交焦虑）。
3. **商业化前置同构**：IAP（抽卡、月卡、通行证、破产礼包）与 IAA（激励视频）不是上线前硬塞的补丁，必须与单局随机波动（Near-miss 差一点翻盘心理）和局外高角色价值（主公/太守/名将）深度咬合，且不破坏公平感与喜剧调性。
4. **不确定性校准（Uncertainty Calibration）**：掷骰游戏天然强随机，必须明确随机性放在**输入端（Input Randomness：掷出点数、刷出三选一祝福、抽到天命签）**还是**输出端**，并赋予玩家足够的**可控干预手段**（遥控骰子、锦囊改步、军师口斗技、装备词条对冲），确保玩家输掉时归因为“我刚才贪了没用锦囊/没留保命钱”，而非“狗策划暗改概率”。
5. **证据与假设边界（Evidence & Assumption Ledger）**：明确区分已验证竞品规律（`external_evidence`）、本案推导设计（`derived`）与待原型测试验证项（`assumption / needs_research`），杜绝无根据的 ROI / DAU 拍脑袋承诺。
6. **范围闸门（Scope Gate）**：清晰切分 MVP（验证单手掷骰绕圈 + 踩城过路费/单挑攻城博弈 + 基础三选一构筑）、Vertical Slice（加入完整台味演出、1位标杆主公+10名太守武将、转职命格树与1个完整章节Boss）、首发版（Release）与明确砍掉的危险包袱（Cut：如实时多人联机等待、复杂RTS手动微操行军）。

### 1.2 体验浓度（ED）模型与竖屏首局心流控制（源自 `game-experience-density-optimizer`）

针对竖屏单手手游碎片化、易流失的特征，引入**体验浓度（Experience Density，简称 ED）**作为局内节奏的设计标尺（标注 `theory_status: design_hypothesis`）：

$$\text{ED} = \frac{\text{MD/min} \times (\text{SF} + \text{EB} + \text{AR})}{\text{CLP}}$$

| 公式项 | 中文定义 | 在本项目的具体映射与设计抓手 |
| :--- | :--- | :--- |
| **MD/min** | 每分钟有意义选择次数 | 非无脑连点掷骰！而是每分钟穿插 2~4 次高价值微决策：开几倍骰子？踩敌城是交钱、单挑还是攻城？三选一选哪个锦囊/命格？城池建箭塔还是建赌场？ |
| **SF** | 可感知反馈（Salient Feedback） | 银两哗啦啦飞入聚宝盆的视听暴击、敌方主公踩中天价巨城时的颜艺惨叫、单挑大招或搞笑“放水”的瞬间反差演出。 |
| **EB** | 具身感加成（Embodiment Bonus） | 底部大拇指按压蓄力掷骰的3D物理碰撞震感（Haptics）、棋子“啪嗒啪嗒”踩格弹跳节拍、纸娃娃换上“金箍棒/折凳”的即时外观反馈。 |
| **AR** | 氛围感加成（Atmosphere Resonance） | 浓厚台湾华人市井烟火气：夜市灯笼、算命摊幡旗、俚语配音腔调、丝竹混搭欢快小调的听觉记忆点。 |
| **CLP** | 认知负荷惩罚（分母，越低越好） | **头号大敌！** 9:16 小屏严禁满屏密密麻麻的三国属性表与复杂兵粮公式；落点数字自动高亮、克制关系用直觉图标（剪刀石头布/箭头）、淘汰装备自动折算银两。 |

* **调优铁律**：「**先判窗口，再降噪（砍 CLP），再提质（拉满 SF/EB/AR），后调频（稳住 MD/min）**」。
* **长线防钝化（Anti-Habituation Plan）**：针对单人绕圈容易产生的中后期审美疲劳，必须通过「每章专属棋盘机制（如赤壁水战船连环盘、南蛮瘴气藤甲盘）+ 主公专属异变规则 + 阶段天命宿敌乱入」持续制造“半熟半新”的可控惊讶（Prediction Error Window）。

### 1.3 喜剧游戏化引擎：UCB 情景喜剧 `Game` 与 `Game 点` 梯级（源自 `sitcom-game-designer`）

《富甲天下》之所以成为几代华语玩家的白月光，绝不只是因为塞了几个谐音梗，而是它天生具备**情景喜剧（Sitcom）的角色喜剧引擎（Character Game）**。立项书的基调圣经与文案设计应严格遵循以下喜剧工程学区分：

1. **Base Reality（常态与现实压力）**：三国乱世争霸，养兵买马、攻城略地都要真金白银；踩进别人地盘没钱交过路费就会破产流落街头——**算账和生存压力必须是真实的，喜剧才立得住**。
2. **First Unusual Thing（可观察的异常行为）**：本该慷慨悲歌的三国英雄，却像台湾菜市场摊贩、里长候选人或地下钱庄讨债鬼一样斤斤计较（例如刘备一边抹眼泪谈匡扶汉室，一边掏出算盘把过路费精确到铜板还强买强卖草鞋）。
3. **Comic Logic / POV（荒谬但自洽的信念）**：人物绝不觉得自己在搞笑，而是深信自己的市井逻辑天经地义。
4. **一句话 Character Game 生成公式**：
   > 每当 **`[触发游戏机制情境：如收过路费 / 单挑开场 / 抽天命签 / 濒临破产]`**，**`[特定主公/武将]`** 就会因为 **`[荒谬但自洽的市井信念]`** 而做出 **`[可重复升级的行为机制]`**，结果让 **`[战场局势 / 钱包 / 英雄面子]`** 变得更加滑稽失控。
5. **Game 点梯级（Heightening 七大升级维度）与 Button（高点收尾）**：
   * 同一主公/事件的笑点不能横向换词重复，而要沿 **Cost（代价变大）**、**Commitment（死鸭子嘴硬到底）**、**Status（在关底魔神面前还搞市井砍价）**、**Inversion（把对手也带偏进自己的荒唐逻辑）** 递进。
   * **Button 原则**：单挑结算、奇遇弹窗、破产动画必须在能量最高点用一句短促精准的台词或动作戛然而止，**严禁解释笑点**。

### 2.2 主公差异化与非对称开局设计

《富甲天下》的主公从不走严肃史诗路线，而是将历史典故转化为**非对称数值特权 + 鲜明喜剧人格**：
* **刘备（仁义算盘精 / 幸运苟活流）**：初始资金偏少，但自带关羽、张飞两员超一流万人敌猛将；**幸运值极高**（踩聚宝盆、赌场、宝箱极易出极品），招募在野武将亲和力高、俸禄折扣，台词表面哭穷仁义，实则最擅长靠兄弟白嫖过路费。
* **曹操（霸道地产商 / 资本碾压流）**：初始银两雄厚、账下谋臣猛将云集（夏侯渊、夏侯惇、荀彧、郭嘉等），城池建设与征税效率高，擅长滚起经济雪球用钞能力砸死对手。
* **孙权（江东水产大亨 / 水战收租流）**：江东子弟水战适性统治级（吕蒙、周瑜、甘宁、太史慈），在水域城池野战与收租具备天然壁垒，擅长稳健守城、连片经营。
* **董卓（暴发户恶霸 / 掠夺拆迁流）**：开局坐拥吕布（武力天花板）与海量西凉兵、高额初始巨款，但声望/魅力极低、武将易被挖角或讨薪；玩法简单粗暴——不搞精细建设，专靠横征暴敛、强抢豪夺与暴力攻城。
* **孟获 / 祝融（南蛮野路子 / 林战召唤流）**：林战无敌，拥有象兵/藤甲等异色兵种与野兽/宠物加成，智力普遍偏低（容易中计），但肉搏与蛮干能力极强。
* **异色/隐藏主公（张角、袁绍、士燮、彻里吉、卑弥呼等）**：如张角主打妖术天师坛与黄巾人海、袁绍主打四世三公阔少败家流、卑弥呼主打倭国奇术与女性武将加成——为手游长线赛季持续推出新主公提供了天然蓝本。

### 2.3 城池经营与踩敌城「交费 vs 单挑 / 野战 / 攻城」核心博弈

这是《富甲天下》区别于传统《大富翁》（踩地只能乖乖掏钱）的**第一灵魂机制**！

#### 2.3.1 城池内部经济生态
* **核心参数**：`城池规模等级`、`人口数`、`农业/商业发展度`、`城防耐久度`、`驻城士兵数`、`留存建设资金`、`驻守太守（及副将/校尉）`。
* **正向雪球**：主公每次回到自家城池可注入资金、补充守军、更换太守、加盖建筑（如粮仓促人口、市集提税率、飞虎营降驻军费）；人口与建筑共同抬高**税收（每圈/每月固定产出）**与**过路费（敌人踩中时的罚金）**；同一州郡占领多座城池触发**连城垄断倍率**。

#### 2.3.2 踩中敌方城池的四择生死博弈矩阵
当玩家停留在敌方城池格时，系统弹出极具张力的四选一决策：

| 决策选项 | 触发条件与战斗形式 | 胜利收益（Reward） | 失败惩罚（Penalty / Risk） | 博弈心理与喜剧张力 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 乖乖缴交过路费** | 直接支付标定银两 | 全身而退，保留兵力与武将体力准备后续夺大城 | 现金流失血，肥了敌方城池金库 | 忍一时风平浪静，配主公肉痛滴血吐槽台词 |
| **2. 单挑（将战）** | 我方派1将（5代为3v3）+1军师 vs 敌城太守+副将 | **免交本次过路费！** 且挫伤敌城士气/太守体力、武将获高额经验 | **赔付双倍过路费！** 出战武将重伤（甚至被俘/降忠） | **以小博大神技！** 哪怕对方十万大军守城，只要我有关羽/吕布配金箍棒，一刀砍翻太守就能白嫖免单大摇大摆走人！ |
| **3. 野战（兵团战）** | 城外按城池地形（**陆/水/林**）派主将+军师+士兵交锋 | **免交过路费！** 大量歼灭敌城守军，为下次攻城铺平道路 | **赔付双倍过路费！** 我方随军士兵惨重折损 | 专治“高武力莽夫太守但守军少/地形被我克制”的城池；军师可埋设陷阱阴人 |
| **4. 攻城战（夺城总攻）** | 随军兵力+攻城机关 vs 敌城墙耐久+全部守军+太守 | **免过路费 + 直接夺取整座城池所有权！** 并吞并城内留存的一半建设金与既有建筑！ | **全军覆没赔夫人又折兵！** 巨额赔款+兵力清空+机关损毁，极易直接破产 | **终极逆转高潮！** 把对手辛苦养肥的满级“摇钱树”连根拔起变成姓自己的，爽感堪比抄家！ |

### 2.4 太守与军师的二元角色职责

* **太守（驻城防守与经营核心）**：
  * **统率**：决定城池驻军上限与攻城/野战时的士兵攻防加成。

### 2.7 灵魂基调考据：「台湾华人市井诙谐幽默」拆解与鲜活台词实例

《富甲天下》的喜剧气质绝不是美式漫威吐槽，也不是大陆网络烂梗堆砌，而是90~00年代台湾单机黄金期（光谱《富甲天下》、大宇《大富翁4》、奥汀《幻世录/三国群英传》坊间文化、周星驰港片国语配音与台湾布袋戏/夜市文化交融）孕育出的**「台湾华人市井诙谐（Taiwanese Streetwise Sitcom Humor）」**。

#### 2.7.1 四大喜剧基因密码
1. **英雄市井化（菜市场与里长伯逻辑）**：把“逐鹿中原”降维成“抢黄金店面收房租”；把“三顾茅庐”演成“高薪挖角兼画大饼不给劳健保”；把“赤壁借东风”变成“气象局不准害我烧错船赔惨了”。
2. **台式国语腔调与闽南语词汇点睛**：自然融入高频、传神、两岸玩家皆能秒懂会心一笑的台味口语——如 **`歹势`（不好意思）**、**`安啦`（放心啦）**、**`代志大条了`（事情闹大了）**、**`紧酸`（快溜）**、**`夭寿哦`（要命哦）**、**`哭夭 / 靠北`（抱怨鬼叫）**、**`憨人有憨福`**、**`俗搁大碗`（便宜又大碗）**、**`搏感情`**、**`芭乐票`（空头支票）**、**`走路工`**、**`扛坝子`**。
3. **歇后语魔改与谐音双关**：前半句一本正经引经据典，后半句急转直下拐到钱袋子或逃跑上；以及建筑/装备/NPC名字的恶搞双关（如`屎夹乐`谐音“死嘉乐/全家乐”、算命仙叫`铁齿铜牙刘伯温表弟`、庸医叫`华陀再世（但医死不赔）`）。
4. **颜艺夸张与尊严扫地反差**：大头Q版武将平时威风凛凛，一旦被收高额过路费或单挑“放水”摔下木马，立刻鼻涕眼泪横流、头顶乌鸦飞过“傻眼……”、抱头鼠窜。

### 3.2 四维属性成长与人生格盘循环

1. **四维核心参数（体能 / 智力 / 魅力 / 道德）的多重耦合**：
   * 在《虚拟人生》中，属性绝非单纯的战斗攻击力面板，而是**奇遇选项锁、转职敲门砖与经济倍率器**：
     * **体能（对应武力/体魄）**：决定HP上限、物理卡牌伤害、打工/征战耐力。
     * **智力（对应谋略/才学）**：决定计谋/法术威力、识破骗局奇遇的概率、解锁高薪文职/军师进阶。
     * **魅力（对应仁德/市井人脉）**：决定商店买装备/锦囊折扣、招募名将成功率、触发红颜/贵人奇遇的隐藏神级选项！
     * **道德 / 名望（双向正邪光谱，极具喜剧张力！）**：并非越高越好！高道德可触发乡民捐款、转职“圣人/天尊/仁君”；**负道德（缺德冒烟）**则能开启黑市销赃、强收保护费、甚至进大牢触发超强隐藏邪道职业（如《虚拟人生》传奇隐藏职业**「囚犯」**或三国恶霸命格**「乱世奸雄/锦帆贼」**）！
2. **循环时间窗压力**：每章限定圈数/步数（如同人生的年龄刻度），玩家必须在「去私塾升属性」、「踩城赚钱搞基建」、「进转职格换高级命格拿神卡」之间做紧凑的路线规划。
